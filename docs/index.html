怎么用

  1. 点击上面的“下载一键安装器”。
  2. 双击 Install_NextTest.cmd；Windows 提示时选择“更多信息 → 仍要运行”。
  3. 等待自动下载、解压、安装 Python 依赖并启动；浏览器会打开工作台。
不要点 GitHub 的 Code → Download ZIP 后直接运行。
源码包需要 Node/npm 构建；普通使用者请用一键安装器或完整运行包。

没有 Python？

安装 Python 3.13，安装时勾选 Add python.exe to PATH：
python.org/downloads/windows。安装后重新双击安装器。
