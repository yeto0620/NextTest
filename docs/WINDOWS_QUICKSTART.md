# Windows 一键启动

NextTest 是**本地 Web 工作台**，不是已经打包好的 exe、Electron 或安装包。双击启动文件后，浏览器会打开本机页面。

## 第一次使用

1. 解压或克隆仓库。
2. 如果需要示例数据，按公开发布手册从 UCI 获取，并通过 Data Dock 的字段检查、质量确认和数据闸门。仓库不附带原始数据或运行产物。
3. 双击 `start_nexttest.cmd`。
4. 等待窗口显示本地地址；浏览器会自动打开。若没有自动打开，手动访问窗口中显示的 `127.0.0.1` 地址。
5. 停止时回到黑色窗口，按 `Ctrl+C`，或直接关闭该窗口。

## 启动失败

双击后的窗口会给出中文修复提示。也可以运行：

```text
start_nexttest.cmd --doctor
```

它会检查 Python 3.13、后端依赖、前端构建、公开发布门禁和可用端口，不启动服务、不联网、不读取数据或项目记录。

不要关闭正在运行的其他服务；启动器会自动选择 8501–8510 中可用的端口。

## 证据助手

没有设置 `NEXTEST_LLM_API_KEY` 时，证据助手会安全显示“未配置”，不会发起网络请求。没有 Key 不影响浏览、历史回放和本地证据查看。

## 不要上传

不要上传 `.env`、API Key、原始数据、`runs`、`artifacts`、`deliverables` 或本机路径。公开发布前运行：

```text
python scripts/verify_public_release.py --check
```

## 边界

- 历史回放不是新物理实验；模型预测不是测量。
- 模型分歧不是概率或置信区间。
- 不声称策略优越、因果、成本节省、工业/临床有效性或泛化。
- 本版本是本地 Web 工作台，不是原生桌面安装包。
