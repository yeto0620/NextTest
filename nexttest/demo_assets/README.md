# Bundled demo assets

These four files are the frozen, hash-checked inputs needed to start the public demo without the development `artifacts/` and `data/` directories:

- `manifest.json`
- `split.json`
- `source_manifest.json`
- `concrete_age28.csv`

They are copied byte-for-byte from the audited P1-R output and the canonical Age=28 view. The app verifies their SHA-256 values before using them. No original workbook, raw download archive, hidden labels or project records are included.

Source: UCI Machine Learning Repository, Concrete Compressive Strength (CC BY 4.0). Citation: Yeh, I. (1998). Concrete Compressive Strength [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5PK67.
